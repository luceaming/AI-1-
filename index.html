        스미싱 6대 위험 신호 기준

        정부·공공기관의 공식 안내 문자는 인터넷 주소(URL)를 포함하지 않는 것이 원칙입니다. 아래 신호 중 2가지 이상이 겹치면 즉시 의심하세요.

        01. 긴급성 압박

        “오늘 자정까지”, “미확인 시 계좌 정지·압류”처럼 당황하게 만들어 확인 없이 누르게 합니다.

        02. 기관·기업 사칭

        검찰·경찰·국세청·건강보험·은행·택배사를 내세워 신뢰를 얻고 거부하기 어렵게 만듭니다.

        03. 출처 불명 URL

        단축 주소나 공식 도메인과 비슷한 가짜 주소를 넣어 피싱 사이트 접속을 유도합니다.

        04. 앱 설치 유도

        사건 열람이나 보안 점검을 이유로 설치 파일(.apk)이나 원격제어 앱 설치를 요구합니다.

        05. 개인정보 요구

        신분증 사진, 비밀번호, 일회용 인증번호, 계좌 비밀번호 입력을 요구하면 100% 의심해야 합니다.

        06. 금전·송금 요구

        합의금, 수수료, 상품권 핀번호, 가족을 사칭한 긴급 송금 요청은 반드시 전화로 직접 확인하세요.

        개인정보 보호 및 안전 원칙

        SafeText Trainer는 사용자가 입력한 문자 내용과 전화번호·계좌번호를 서버 데이터베이스에 저장하지 않습니다. 다만 무료 AI 모델 특성상 민감한 실명, 계좌번호, 전화번호는 입력 전 마스킹 버튼을 눌러 지운 뒤 분석하시길 권장합니다.
